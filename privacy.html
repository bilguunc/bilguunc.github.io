Privacy Policy — Policy Assistant

Last updated: 27 November 2026

Who uses it

Policy Assistant is a private tool used only by its developer, on their own computer. It has no other users.

Google data it uses

  • Scope: https://www.googleapis.com/auth/notebook (Gemini Notebook).
  • Purpose: to add the user's own meeting recordings as sources to the user's own notebook, and to list that user's notebooks and sources.

What it does not do

  • It does not read, store or copy any other Google account data.
  • It does not sell, share or transfer Google user data to anyone, and does not use it for advertising.
  • It does not use Google user data to train AI or machine-learning models.

Storage

The sign-in token is kept only in the user's own automation tool on their own computer. The user can revoke access at any time at myaccount.google.com/permissions.

Limited use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
